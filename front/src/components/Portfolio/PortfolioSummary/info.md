🔄 Как текут данные и работает логика

Источник данных: Бэкенд (PortfolioService) возвращает массив PortfolioItem[], где для каждой монеты уже рассчитаны totalValue, realizedPnl, pnl (unrealized), totalInvested (сумма всех BUY) и change24h.

Агрегация в useMemo: Компонент проходит по массиву один раз и суммирует метрики в локальные аккумуляторы. Это чистая трансформация данных без побочных эффектов, что соответствует правилам React Purity.

Расчёт totalValueYesterday: Поскольку бэкенд отдаёт только % изменения за 24ч, мы восстанавливаем вчерашнюю стоимость через обратную формулу Current / (1 + %/100). Это позволяет точно вычислить абсолютное изменение портфеля в долларах и общий % за сутки.

База для ROI (totalGrossInvested): Вместо netInvested (который уменьшается при продажах и ломает процент при выводе средств) используется историческая сумма всех покупок. Это гарантирует, что +54 420$ при вложенных 100 000$ всегда покажет честные 54.42%, независимо от того, выводил ты прибыль или реинвестировал.

Рендер: Вычисленные значения форматируются через fmt/fmtSign, динамически подбираются CSS-классы (up/down/neutral) и стрелки. Блок "Реализованный" рендерится условно, чтобы не захламлять UI нулями, если продаж ещё не было.

Производительность: useMemo пересчитывает статистику только при изменении ссылки на массив items. DOM-обновления минимальны, побочных эффектов в рендере нет.
