КАК ТЕКУТ ДАННЫЕ (КРАТКО)
Транзакция → фон → атомарная запись 1h
CRUD коммитит сделку, мгновенно возвращает ответ и запускает rebuild() в фоне. Сервис проходит все сделки, считает стоимость, добавляет рыночный хвост из Redis и атомарно заменяет только часовые точки.
Cron → живая динамика + агрегация
Раз в час добавляется рыночный снимок. По расписанию запускаются rollup-джобы (1h→1d→1w→1m), создают старшие уровни и удаляют просроченные строки. Объём БД стабилизируется на ~322 точках/пользователь.
Контроллер → мгновенная выборка
API обращается к нужной гранулярности, выбирает 20–60 строк за 2–4 мс, прореживает с сохранением границ, отдаёт JSON.
Фронтенд → детерминированный рендер
React Query кэширует ответ, useMemo трансформирует в [timestamp, value], ECharts рисует логарифмическую кривую с жёсткими min/max оси X. Шапка показывает актуальную стоимость из последней точки.
